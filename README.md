## Windows EPUB association

Run `pnpm build` once, then associate `.epub` files with [open-epub.bat](D:/Users/Client/Documents/Coding/Epub%20Reader/open-epub.bat). Double-clicking an EPUB starts the local static reader only when needed and opens that book in Chrome. Its helper exits after ten minutes without requests.

I built it because I needed a lightweight, 0 bloat epub reader that works in the browser.
